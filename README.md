# Corrector de Semblanzas Escolares

Primera versión visual del frontend, realizada con React + Vite.

## Requisitos
- Node.js (versión LTS actual)
- npm

## Ejecutar
1. Descomprimí la carpeta.
2. Abrí una terminal dentro de `corrector-semblanzas`.
3. Ejecutá `npm install`.
4. Ejecutá `npm run dev`.
5. Abrí en el navegador la dirección local que muestra Vite (normalmente http://localhost:5173).

## Estado de esta versión
La pantalla, los selectores, el contador, limpiar, copiar y descargar ya funcionan.
El botón «Corregir semblanza» todavía no llama a una IA: muestra un aviso porque falta conectar el backend y el servicio de inteligencia artificial. No se envía ni se guarda el texto.
